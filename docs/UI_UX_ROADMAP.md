# UI/UX 改善ロードマップ

最終更新: 2026-07-11

## デザインの基準

- タイトルの「出勤する」「ランキング」ボタンは現状かなり良い。今後の共通UIは、この太いオレンジ枠、濃紺、生成り、ハードな影を基準にする。
- 画面ごとに別の装飾を増やすより、色・余白・文字サイズ・ボタン状態を共通化する。
- 給与明細や発車標など、世界観に理由のあるUIは残す。汎用的なゲームUIへ均す必要はない。
- アセットは雰囲気を決める装飾層として使い、ゲーム固有の導線や情報設計は自前で保つ。

## P0: 次に着手したいもの

### 1. InGameの遊び方導線

現状はゲーム内で基本操作と目的が明記されていない。HUDには空席を見たときの `E 座る` だけが出るため、初見では「何を競っているか」が分かりにくい。

現在の操作:

- マウス: 視点操作
- `WASD` / 矢印キー: 移動
- `E`: 視線の先にある空席へ座る
- コーヒー、データメガネ: 接触すると自動取得
- 空席は他の乗客も狙う。先に座るとその日を生き延び、立ち続けると体力が減る。

推奨する実装順:

1. タイトルに「遊び方」ボタンを追加する。
2. 初回プレイだけ、開始直後に3枚以内の短いチュートリアルを表示する。
   - 「空席を探せ」
   - 「近づいて中央に捉え、Eで座れ」
   - 「乗客より先に座り、体力を守れ」
3. 初めて空席が発生した瞬間だけ、対象席と `E` プロンプトを強める。
4. 一度見た説明は自動表示せず、タイトルとポーズ画面から再確認できるようにする。

長い説明画面を最初に読ませるより、「目的を先に一文」「操作は必要になった瞬間」の二段構成が合う。

### 2. ポーズメニュー

`Esc` は現在カーソルを解放するだけなので、正式な一時停止画面へ置き換える。

最低限必要な項目:

- ゲームに戻る
- 遊び方
- 設定
- タイトルへ戻る

実装時の注意:

- `Time.timeScale = 0` とカーソル解放を同時に行う。
- ランキング、給与明細、日替わりカットイン中はポーズ入力と競合させない。
- 再開時にカーソルを確実にロックし直す。
- 各コンポーネントが直接キーを読む状態を増やさず、ポーズ中かどうかを共通状態で参照する。

### 3. 音量・基本設定

まず必要な設定:

- マスター音量
- BGM音量
- SE音量
- マウス感度
- フルスクリーン / ウィンドウ

設定は `PlayerPrefs` 等へ保存し、タイトルとポーズ画面の両方から同じ `SettingsView` を開く。音量は可能なら `AudioMixer` の Master / BGM / SFX グループで管理する。

## P1: UIの「AIっぽさ」を減らす

現在はコード生成UIを画面ごとに直接組んでおり、個々は整っていても、余白・文字階層・パネル表現が少しずつ異なる。ここが「それっぽい部品を並べた感」の主因になりやすい。

改善案:

- `UiKit` に色、余白、文字サイズのデザイントークンをまとめる。
- 共通のモーダル枠、セクション見出し、スライダー、トグル、戻るボタンを用意する。
- タイトルボタンのホバー・押下表現を共通ボタンの基準にする。
- HUDは常時表示を増やしすぎず、必要な情報だけ段階的に出す。
- 1920×1080だけでなく、16:10と小さめウィンドウでも文字切れを確認する。

### アセット導入の考え方

導入するなら、完成済みメニュー一式より次のような素材が相性よい。

- 日本語対応の見出し・本文フォント
- 駅サイン用ピクトグラムと操作キーアイコン
- 紙、印刷かすれ、金属、LEDドットなどの控えめなテクスチャ
- UI用の短い決定音、戻る音、スライダー音

完成済みUIアセットをそのまま当てると、タイトルボタンや給与明細の個性と衝突する可能性がある。先に共通レイアウトを固め、装飾だけ差し替えられる構造にしてから選定する。

## P2: その後の候補

- キーボード以外の入力とキーコンフィグ
- 色覚差に配慮した、色以外の状態表示
- ランキングのオンライン共有。現在はローカル上位10件のみ
- 初回チュートリアルを見たか、どこで離脱したかの簡易計測
- 設定画面とポーズ画面の開閉アニメーション、専用SE
- リザルトから「次に改善すべきプレイ」を一言返すフィードバック

## 次回のおすすめ着手順

1. ポーズ画面の骨組みと共通モーダルを作る。
2. その中へ「遊び方」と「設定」を載せる。
3. 同じ「遊び方」「設定」をタイトルからも開けるようにする。
4. 初回プレイ用の短いチュートリアルを追加する。
5. 最後にフォント・アイコン・テクスチャのアセットを選定する。

この順なら、新しく作る画面を使い捨てず、タイトルとInGameの双方で再利用できる。
