# UIデザイン方針 — 「座れ！サラリーマン！」

UIを足す・直すときは必ずこの方針に従う。目的はふたつ：**世界観（社畜×通勤）を全UIで貫くこと**、**「AIが作った風」の没個性UIを排除すること**。

## 1. 世界観の型（どの意匠を使うか）

UIは必ず次の3つの「モノ」のどれかとして作る。画面に浮いた抽象パネルを作らない。

| 型 | 使いどころ | 実例 |
|---|---|---|
| **紙の書類**（クリーム紙＋墨文字＋赤い判子） | 成績・通知・説明など「会社から渡されるもの」 | 給与明細リザルト、研修のしおり |
| **LED発車標**（暗い盤面＋アンバー/生成りの文字） | 一覧・速報など「駅が掲示するもの」 | 社畜ランキング |
| **駅サイン/掲示札**（紺地＋オレンジ帯＋白文字） | HUD・メニューなど「常設の案内」 | 左上HUDカード、ポーズメニュー、タイトル |

文言も世界観の語彙で書く。例：閉じる→「退勤する」、リトライ→「もう一度出勤する」、ポーズ→「小休止中」、空欄→「（欠員）（回送）」、注記は人事部・総務部の上から目線で。

## 2. パレット（これ以外の色を増やさない）

- 紺（地）: `#212636` 系 / 深紺 `#0D0F1A`
- クリーム（紙・文字）: `#F0EEE3`
- 差し色オレンジ（中央線）: `#F27326` — 使いすぎない。帯・下線・強調のみ
- 判子の赤: `#D12920` — 印・警告・控除のみ
- LEDアンバー: `#FF7A33` / LED文字は生成り
- 体力ゲージのみ緑→黄→赤の信号色を許可

## 3. 「AIっぽさ」を消すルール

AI感の正体は「均一な角丸＋ぼかし影＋等間隔グリッド＋無個性文言」。以下を守る：

1. **角丸＋ふんわり影のカード連発禁止**。影を使うなら「ハードなオフセット影（ぼかさない）」
2. **要素をわずかに崩す**：判子は必ず傾ける（-7〜13°）、スタンプ演出は2.2倍→等倍のパンチ
3. **文言に人格を持たせる**（§1の語彙）。「OK」「Close」「Settings」のような無味な単語を出さない
4. **演出は物理的な所作**にする：手渡される・判子が押される・LEDが点滅する。フェード/スライドだけで済ませない
5. 絵文字をUIに使わない（例外：現状の🚉は要置換候補）

## 4. ボタンの基準（＝タイトルのボタン。変えるときはUiKitごと）

`UiKit.MakeButton` が唯一のボタン実装。**個別画面で独自ボタンを作らない。**
- シャープな角（角丸なし）／太いオレンジ縁／ネイビー面／クリーム文字
- ハードオフセット影（+9,-9）。ホバー：面がオレンジに反転し、見た目だけ浮く（判定は動かさない＝チカチカ防止）
- 押下：影へめり込む
- スライダーは `UiKit.MakeSlider`（オレンジ塗り＋丸ノブ）

## 5. UIアセットを導入する場合の選定基準

1. **フラット/幾何学系**であること（グラデ・スキュアモーフィック・ファンタジー装飾は不採用）
2. **9スライス対応**のシンプルなフレーム/下地が主体で、上記パレットに染色して使えること（白ベース素材）
3. **和文と喧嘩しない**こと（にくまるフォントと並べて浮かないか必ず実機確認）
4. ライセンス：商用可・クレジット任意を優先。**外部アセットはgit禁止ルール**（.gitignore＋READMEに再取得手順）
5. 導入しても**UiKitの窓口は維持**する（呼び出し側は差し替えを知らない）

## 6. 実装規約

- ビュー層はロジックを持たない（描画専用）。ルールはCore/システム側
- 実行時マテリアルは `RuntimeMaterials`（テンプレ.mat複製）経由。`Shader.Find`直呼び禁止（ビルドでピンク化する）
- 演出は unscaled 時間で駆動（timeScale=0でも動く）
- レイアウトは「親の端に固定」(EdgeTop/anchor) で組む。中央ピボット＋固定座標ではみ出させない
- ボタン類は必ずパネルの**内側**に置く
